# Rock Paper Scissors Lizard Spock

## Project Description

This project is a Java implementation of the Rock Paper Scissors Lizard Spock game.

The game allows the user to:

* Choose between Scissor, Rock, Paper, Lizard, and Spock.
* Play multiple rounds.
* View the score after each round.
* Quit the game when desired.

### Rules

* Scissor beats Paper and Lizard
* Rock beats Scissor and Lizard
* Paper beats Rock and Spock
* Lizard beats Paper and Spock
* Spock beats Scissor and Rock

The computer randomly selects a choice each round and the winner is determined using the rules above.
